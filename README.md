# Centro de Lutas VS — Landing

Projeto de landing page (Vite + React + TanStack Start) da Academia Victor Simon RFA.

## Pré-requisitos
- Node.js 18+ ou equivalente
- npm (ou bun/pnpm, ajustando comandos)

## Instalação

Instale dependências:

```
npm install
```

Execute em modo desenvolvimento:

```
npm run dev
```

Gerar build de produção:

```
npm run build
```

Pré-visualizar o build:

```
npm run preview
```

## Imagens / Avatares
Coloque imagens públicas na pasta `public/` (já usada pelo projeto). Exemplo:

- `public/victor-simon.jpg`
- `public/luan-hakym.jpg`
- `public/joao-rosa.jpg`
- `public/bruno-ribeiro.jpg`

O componente de professores já referencia essas imagens como `/nome-arquivo.jpg`.

## Git
O projeto já contém um arquivo `.gitignore`. Para subir ao Git remoto siga:

```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <URL_DO_SEU_REPOSITÓRIO>
git push -u origin main
```

## Observações
- Ajuste o arquivo `.gitignore` se quiser manter arquivos específicos fora do controle de versão.
- Se usar um provedor (GitHub/GitLab), adicione `README.md` e uma descrição no repositório remoto.
